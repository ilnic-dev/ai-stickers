# AI Stickers

**Напиши мысль боту в Telegram — она появится стикером на экране Mac.**

[English version](README.md)

![Панель идей, выпавшая из меню-бара, и два стикера, закреплённых на столе](docs/screenshot.png)

Идеи приходят в случайный момент и теряются в десятке чатов и заметок.
AI Stickers даёт им один вход: личного бота в Telegram. Пишешь или наговариваешь сырую мысль,
и через несколько секунд она висит на маке короткой аккуратной запиской: сводка и список дел.
Записки в одном клике от меню-бара, а нужные можно закрепить прямо на рабочем столе.

## Как это работает

```
Telegram  ──►  AI Stickers.app на маке
(текст или голос)  │
                   ├─ голос → текст локально: ffmpeg + whisper.cpp
                   ├─ текст → стикер через твой `claude` CLI (Haiku):
                   │    заголовок · сводка в 1–3 предложения · задачи · до 2 твоих тегов
                   └─ стикер → в панель идей под иконкой в меню-баре
```

- **Без сервера.** Приложение само опрашивает Telegram. Telegram хранит сообщения 24 часа,
  поэтому мысли, отправленные, пока мак спал, придут, когда он проснётся.
- **Без API-ключей.** Сводки делает `claude` CLI по твоей подписке Claude.
- **Ничего не теряется.** Если Claude не ответил, стикером станет исходный текст.

## Возможности

- **Иконка 📝 в меню-баре** с числом актуальных идей рядом. Клик открывает панель; клик мимо, повторный клик по иконке или Esc закрывают её.
- **Карточка раскрывается при наведении**: сводка, задачи с чекбоксами (галочки сохраняются), теги и удаление с возможностью отменить его в течение нескольких секунд.
- **Теги.** Чипы-фильтры в шапке панели, можно выбрать несколько. На карточке `×` убирает тег, «+ тег» добавляет существующий или новый.
- **Голосовые на смеси русского и английского** распознаются правильно: английские термины остаются латиницей, а стикер пишется на языке, на котором ты в основном говорил.
- **`#тег` в сообщении** ставит этот тег сразу. Claude добавит ещё до двух, но только из тех, что у тебя уже есть.
- **«позже»** — встроенный тег для неактуального: такие идеи скрыты, одна кнопка показывает их снова.
- **Закрепление на столе.** Вытащи карточку из панели, и она станет отдельным стикером. Двигай его за ручку ✥, наведи, чтобы увидеть задачи, одной кнопкой верни в панель.
- **Правый клик по иконке** открывает меню: показать идеи, автозапуск, язык интерфейса, выход.
- **Интерфейс на русском или английском**, переключается в меню-баре («Язык / Language»); по умолчанию — язык системы. Стикеры остаются на языке, на котором ты их надиктовал.
- **Стартует при входе в систему**, без иконки в Dock; одновременно работает только одна копия.

## Что нужно

- macOS 14 или новее
- Xcode или Command Line Tools (для сборки)
- [Homebrew](https://brew.sh): `brew install ffmpeg whisper-cpp`
- Модель whisper.cpp с [huggingface.co/ggerganov/whisper.cpp](https://huggingface.co/ggerganov/whisper.cpp/tree/main): `ggml-large-v3.bin` (3 ГБ, рекомендуется: понимает русский вперемешку с английским) или `ggml-small.bin` (быстрая, но хуже на смешанной речи)
- Установленный и залогиненный [Claude Code](https://claude.com/claude-code) (команда `claude`)
- Аккаунт в Telegram

## Установка

1. **Создай бота.** Напиши [@BotFather](https://t.me/BotFather), отправь `/newbot`, скопируй токен.
2. **Создай конфиг** `~/.config/ai-stickers.env`:

   ```
   TELEGRAM_BOT_TOKEN=123456:ABC...
   ```

3. **Собери и установи:**

   ```bash
   git clone https://github.com/nitsiyevskii/ai-stickers.git
   cd ai-stickers
   ./scripts/install.sh
   ```

   Скрипт собирает `AI Stickers.app`, кладёт его в «Программы», запускает и добавляет
   в объекты входа. Та же команда обновляет приложение после `git pull`.

4. **Привяжи бота к себе.** Напиши ему что угодно. Он ответит твоим Telegram ID; добавь его в конфиг:

   ```
   TELEGRAM_USER_ID=123456789
   ```

   И перезапусти приложение (правый клик по иконке в меню-баре → «Выйти», потом открой AI Stickers из «Программ»).
   С этого момента бот принимает сообщения только от тебя.

## Настройки

`~/.config/ai-stickers.env`, по одной строке `КЛЮЧ=значение`; строки, начинающиеся с `#`, — комментарии.

| Ключ | Обязателен | По умолчанию |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | да | — |
| `TELEGRAM_USER_ID` | да, после шага 4 | — |
| `WHISPER_MODEL` | нет | `ggml-large-v3.bin` в `~/.cache/hyperframes/whisper/models/`, если есть, иначе `ggml-small.bin` там же |
| `WHISPER_PROMPT` | нет | — (дополнительные слова для распознавания, например `Notion, Figma, мой-проект`) |
| `FFMPEG` | нет | `/opt/homebrew/bin/ffmpeg` |
| `WHISPER_CLI` | нет | `/opt/homebrew/bin/whisper-cli` |
| `CLAUDE_BIN` | нет | `~/.local/bin/claude` |

Пути — только абсолютные: у приложения, запущенного при входе, нет `PATH` из терминала.
`WHISPER_MODEL` укажи туда, куда сохранил модель.

Стикеры хранятся в `~/Library/Application Support/AiStickers/stickers.json`.

## Приватность

- **Голос** распознаётся на маке, аудио больше никуда не уходит.
- **Текст** каждой идеи и названия твоих тегов уходят в Claude через твой `claude` CLI, чтобы сделать сводку.
- **Telegram** передаёт сообщения, как у любого бота. Токен лежит только в локальном конфиге и не попадает в логи.
- **Стикеры** — локальный JSON-файл. Ни сервера, ни аккаунта, ни аналитики.

## Разработка

```bash
swift build && swift test   # проверка любого изменения
swift run                   # запуск для разработки: без автозапуска и без проверки второй копии
```

| Файл | Что делает |
|---|---|
| `Sources/AiStickers/main.swift` | конфиг, меню в меню-баре, автозапуск, старт |
| `Sources/AiStickers/Bot.swift` | опрос Telegram, голос → текст, идея → стикер через `claude -p` |
| `Sources/AiStickers/Store.swift` | модель стикера, хранение в JSON, фильтры и теги (чистая логика с тестами) |
| `Sources/AiStickers/Board.swift` | окна: панель из меню-бара, закреплённые стикеры, перетаскивание |
| `Sources/AiStickers/Views.swift` | SwiftUI-представления |
| `scripts/install.sh` | сборка и установка `AI Stickers.app` |

Обычный SwiftPM, без зависимостей. Каждое изменение идёт через свою ветку и PR с описанием,
что поменялось и как работает. Правила для разработчиков и агентов — в [CLAUDE.md](CLAUDE.md)
и [AGENTS.md](AGENTS.md).

## Ограничения

- Пока вход только через Telegram.
- Приложение собирается и подписывается ad-hoc на твоём маке; готовой нотаризованной сборки нет.
- Цвета тегов идут по алфавиту, поэтому новый тег может сдвинуть цвета остальных.
