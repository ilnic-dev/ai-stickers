# AI Stickers

Мысли из Telegram становятся стикерами на экране Mac.

Пишешь боту текстом или голосом, а приложение на маке делает так:

1. забирает сообщение из Telegram (long polling, без своего сервера: пока мак спит, Telegram хранит сообщения до 24 ч);
2. голосовое распознаёт локально (`ffmpeg` + `whisper-cli`);
3. сжимает мысль в стикер через `claude -p` (Haiku, по твоей подписке, без API-ключа): заголовок, короткая сводка, задачи, 0–2 тега из уже существующих;
4. кладёт стикер в панель «Идеи» у левого края экрана.

## Как пользоваться

- **Язычок у левого края** показывает число актуальных идей. Наведи на него, и выдвинется панель.
- **Карточка раскрывается при наведении**: сводка, задачи с чекбоксами, теги, удаление.
- **Теги.** Чипы в шапке панели фильтруют список; можно выбрать несколько. На раскрытой карточке `×` убирает тег, «+ тег» добавляет существующий или новый.
- **`#тег` в сообщении боту** ставит этот тег сразу.
- **Тег «позже»** прячет неактуальное; внизу списка есть «Показать отложенные».
- **Булавка в шапке** держит панель открытой.
- **Перетащи карточку на стол**, и она станет закреплённым стикером. Закреплённый стикер раскрывается при наведении, а кнопка «Вернуть в панель» убирает его обратно.

## Установка

Нужно: macOS 14+, `brew install ffmpeg whisper-cpp`, модель whisper (`ggml-small.bin`), установленный и залогиненный `claude`.

1. Создай бота у [@BotFather](https://t.me/BotFather) и скопируй токен.
2. Создай `~/.config/ai-stickers.env`:

   ```
   TELEGRAM_BOT_TOKEN=123456:ABC...
   # TELEGRAM_USER_ID появится после первого сообщения боту
   # необязательно, ниже значения по умолчанию:
   # WHISPER_MODEL=~/.cache/hyperframes/whisper/models/ggml-small.bin
   # FFMPEG=/opt/homebrew/bin/ffmpeg
   # WHISPER_CLI=/opt/homebrew/bin/whisper-cli
   # CLAUDE_BIN=~/.local/bin/claude
   ```

3. Собери и установи приложение:

   ```bash
   ./scripts/install.sh
   ```

   Скрипт собирает `AI Stickers.app`, кладёт его в «Программы» и запускает. Та же команда обновляет приложение после изменений в коде.

4. Напиши боту что угодно. Он ответит твоим Telegram ID: допиши `TELEGRAM_USER_ID=...` в конфиг и перезапусти приложение («Выйти» в меню, потом открой «AI Stickers» из «Программ»). Сообщения от других людей бот игнорирует.

## Меню-бар

Иконка 📝 сверху справа означает, что приложение работает. В её меню:

- **Показать идеи** — выдвигает панель;
- **Запускать при входе** — галочка автозапуска; включён по умолчанию, виден в «Системные настройки → Основные → Объекты входа»;
- **Выйти** (⌘Q).

В Dock приложения нет. Второй экземпляр не запускается: два бота мешали бы друг другу в Telegram.

Стикеры хранятся в `~/Library/Application Support/AiStickers/stickers.json`.

## Устройство

| Файл | Что делает |
|---|---|
| `Sources/AiStickers/main.swift` | конфиг, меню в меню-баре, автозапуск, запуск |
| `scripts/install.sh` | сборка `AI Stickers.app` и установка в «Программы» |
| `Sources/AiStickers/Bot.swift` | Telegram long polling, распознавание голоса, сжатие через Claude |
| `Sources/AiStickers/Store.swift` | модель стикера, хранение в JSON, фильтр и теги |
| `Sources/AiStickers/Board.swift` | окна: язычок, панель, закреплённые стикеры, перетаскивание |
| `Sources/AiStickers/Views.swift` | SwiftUI-вид панели, карточек и стикеров |

Проверка: `swift build && swift test`.

Если Claude не ответил, мысль всё равно сохранится: стикером станет сырой текст.
